# m3u8bot — ArzanMediaBot 🎬

ربات تلگرام دانلود m3u8 / ساخت زیرنویس فارسی با Gemini.

## دیپلوی روی Railway

1. پروژه جدید → Add Service → از همین ریپو
2. این env ها رو ست کن:

| متغیر | لازم | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از BotFather |
| `ADMIN_IDS` | ✅ | آیدی عددی ادمین‌ها با کاما: `8043083463` |
| `GEMINI_KEY` | نه | کلید Gemini (یا بعداً با `/setkey` داخل ربات) |

3. دیپلوی کن — تمام. به پورت عمومی نیازی نیست (polling می‌کنه).

## نکته‌ها

- فقط ادمین‌ها جواب می‌گیرن (غیرادمین نادیده گرفته میشه).
- کوکی یوتیوب: فایل `cookies.txt` رو توی چت ربات بفرست.
- خروجی‌های موقت توی `WORKDIR` (پیش‌فرض `/tmp/m3ubot`) ساخته و بعد تحویل پاک میشن.
